# Customa PHP Client

This repository contains the official PHP client for [Customa](https://www.customa.de). It is generated automatically using the [OpenAPI Generator](https://openapi-generator.tech) from the OpenAPI Specification of the [Customa REST API](https://docs.customa.biz/rest-api/).

To install the Client in your PHP project, add the `tid/customa` dependency to your composer.json.
